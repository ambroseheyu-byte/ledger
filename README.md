# 小账本

一个按预算分类记账的网页应用，适合用在 iPhone 上。可以添加到主屏幕，像 App 一样打开，**没网也能用**。数据只保存在你自己的手机上，不需要注册账号，也不会上传到任何服务器。

👉 **在线使用：https://ambroseheyu-byte.github.io/ledger/**

---

## 功能

- **五类预算**：吃饭、零碎、储蓄、学习、恋爱。每一类都有自己的月额度。
- **两个进度条**：
  - 吃饭：本月进度和今日进度（默认每天 30 元）。
  - 其他四项：本月进度和本周进度。每周额度按「月额度 × 7 ÷ 当月天数」自动计算。
  - 进度条走满，说明这部分额度已经用完。超支时会变成红色。
  - 储蓄的进度条表示存了多少，走满就是这个月的储蓄目标完成了。
- **本月还能花多少**：页面顶部显示除储蓄以外还剩多少预算。
- **记账**：点底部的「+」记一笔。也可以直接点某张卡片，会自动选好那一类。每笔可以写备注、选日期。
- **明细**：按天列出每一笔。点「删除」后再点「确认删除」才会删掉。
- **切换月份**：点顶部的左右箭头，可以查看以前的月份。
- **自定义预算**：在右上角设置里修改每一类的月额度和每天的吃饭额度。
- **备份和恢复**：在设置里可以导出或导入备份（JSON 文件）。
- **深色模式**：会跟着手机系统设置自动切换。

默认预算（月收入 2600 元）：

| 类别 | 月额度 | 第二条进度 |
|---|---|---|
| 吃饭 | 900 | 每天 30 |
| 储蓄 | 650 | 每周约 152 |
| 零碎 | 300 | 每周约 70 |
| 学习 | 200 | 每周约 47 |
| 恋爱 | 550 | 每周约 128 |

> 每周额度会跟当月天数有关，表里是按 30 天的月份算的。

## 安装到 iPhone

1. 用 **Safari** 打开上面的网址（必须是 Safari，其他浏览器不支持添加到主屏幕）。
2. 点底部中间的「分享」按钮。
3. 往下滑，选「**添加到主屏幕**」，再点「添加」。
4. 从主屏幕的图标打开一次，等它缓存完成。之后断网也能正常使用。

> 安卓手机：用 Chrome 打开网址，在右上角菜单里选「添加到主屏幕」或「安装应用」。

## 关于数据，请一定看一下

- 所有记录**只存在当前这台手机上**，别人打开同一个网址只会看到一个空白账本。
- 请**从主屏幕的图标打开**。直接在 Safari 里打开网址的话，iOS 可能在一段时间不用后自动清掉数据。
- **删除主屏幕图标会把记录一起删掉**。删除前先导出备份。
- 建议**每个月导出一次备份**：进入右上角设置，点「导出备份」，然后保存到「文件」App，或者发给自己。
- 换手机时，在新手机上打开设置，点「导入备份」，选择之前导出的文件就能恢复。导入时会跳过重复的记录，不会把数据重复导入。

## 想部署一份自己的？

不需要会写代码，用电脑浏览器就能完成：

1. 注册或登录 [GitHub](https://github.com)。
2. 打开本仓库，点右上角的 **Fork**，复制一份到你自己的账号下。
3. 进入你 fork 出来的仓库，点 **Settings** → **Pages**。在 Branch 里选 `main`，后面保持 `/ (root)`，点 **Save**。
4. 等 1～2 分钟，你的网址会是 `https://你的用户名.github.io/ledger/`。

预算不需要改代码，直接在 App 右上角的设置里改就可以。

如果想改默认预算或分类名称，编辑 `index.html` 里的这两行：

```js
const CATS=[ ... {k:'food',n:'吃饭', ...}, ... ];   // n 是显示的名称
const DEF={food:900,misc:300,save:650,learn:200,love:550,foodDay:30};   // 默认额度
```

## 更新以后手机没变化？

App 会把页面缓存到手机上，所以改了文件以后要更新缓存版本：

1. 打开 `sw.js`，把第一行的 `xzb-v1` 改成 `xzb-v2`（以后每次更新就继续加 1）。
2. 提交修改。
3. 在手机上把 App 完全关掉，再重新打开一两次，就会换成新版本。

不用担心记录丢失，更新版本不会删除已有数据。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 整个 App 的页面和逻辑 |
| `manifest.json` | App 名称、图标、全屏显示设置 |
| `sw.js` | 离线缓存 |
| `icon-180.png` / `icon-192.png` / `icon-512.png` | 主屏幕图标 |

纯 HTML、CSS 和 JavaScript 写成，没有依赖，也不需要编译。
